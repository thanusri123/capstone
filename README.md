# 🛍️ Capstone E-Commerce Project

A full-stack e-commerce platform built as a capstone project to showcase my development skills.

## 📂 Project Structure

- **/ecom-web/** — Frontend built using React (deployed on Vercel)
- **/backend/** — Backend API using Node.js & Express
- **/android/** — Mobile application version 
- **/build/** — Production build files 
- **/ecom-server/** 

## 🚀 Live Demo

- **Frontend (Vercel)**: [https://-link.vercel.app](#)
- **Backend **: [“Not Deployed”]

## 💻 Tech Stack

- **Frontend**: React, HTML/CSS, JavaScript
- **Backend**: Node.js, Express
- **Database**: MongoDB / MySQL
- **Mobile**: Java / Kotlin 
- **Tools**: Git, GitHub, Vercel, Postman

## ✨ Features

- User authentication and authorization
- Product browsing and search
- Shopping cart functionality
- Order history and checkout
